## 一、提示词公式

## 二、我的常用提示词模板

### 1. 周报生成
```
请帮我整理本周工作：
[列出任务清单]

生成正式周报，包含：
- 完成事项（带进度）
- 待办事项
- 风险和问题
- 下周计划
```

### 2. 邮件模板
```
写一封 [类型] 邮件：
- 收件人：[身份]
- 目的：[目标]
- 关键信息：[要点]
- 语气：[专业/友好/坚决]
```

### 3. 学习计划
```
我想在 [时间] 内学会 [技能]。
当前水平：[描述]
可用时间：[每天/每周 X 小时]

请制定详细学习计划，包含：
- 学习路径
- 推荐资源
- 时间节点
- 实践项目
```

### 4. 代码审查
```
请审查以下代码：
[粘贴代码]

指出：
1. 潜在 bug
2. 性能问题
3. 可读性改进
4. 安全漏洞
```

---

## 三、高级技巧

### 1. 思维链（Chain of Thought）
让 AI 一步步思考，提高准确性：

"请一步步思考并解答：
[问题]"

### 2. Few-Shot Learning
给几个例子，让 AI 模仿：

"参考以下示例，生成类似内容：
示例 1：...
示例 2：...
现在请生成：..."

### 3. 角色设定
"你现在是 [角色]，请以此身份回答：
[问题]"

### 4. 限制输出
"请用 3 句话总结..."
"请列出 TOP5..."
"请用表格形式..."
