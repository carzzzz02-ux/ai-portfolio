## 💡 爆款内容公式

### 小红书
```
爆款标题 = 数字 + 痛点/收益 + 情绪词
例如："7 天涨粉 3000！我的小红书起号秘籍‼️"

爆款封面 = 清晰 + 对比 + 文字说明
例如：前后对比图 + 大字标题

爆款内容 = 分段 + emoji + 实用干货
```

### 知乎
```
爆款回答 = 开头结论 + 数据/案例 + 逻辑清晰
例如："谢邀。我用 AI 做副业，月入 2 万，分享 5 个真实可行的方法。"

高赞特征：
- 前 3 行抓住注意力
- 有数据支撑
- 有实操步骤
- 结尾有总结
```

### 公众号
```
爆款文章 = 热点/痛点 + 深度分析 + 实用建议
例如："2026 年，普通人用 AI 赚钱的最后机会"

10 万 + 特征：
- 标题吸引点击
- 开头有故事
- 内容有共鸣
- 结尾有金句
```

## ⚠️ 常见坑及应对

### 坑 1：发了内容没人看

**原因**：
- 内容质量不够
- 标签/话题不对
- 发布时间不对

**应对**：
- 研究爆款内容
- 优化标题和封面
- 调整发布时间

---

### 坑 2：有流量没转化

**原因**：
- 产品描述不清晰
- 价格太高
- 信任度不够

**应对**：
- 优化产品页
- 添加用户好评
- 设置限时优惠

---

### 坑 3：坚持不下去

**原因**：
- 前期没正反馈
- 内容创作太累
- 看不到希望

**应对**：
- 设定小目标（如先赚第 1 块钱）
- 找同行交流
- 记住：30 天才开始见效
