## 📝 内容创作 SOP

### 小红书创作流程（30 分钟/篇）
```
1. 选题（5 分钟）
   - 查看热点
   - 确定角度

2. 写标题（5 分钟）
   - 5 个备选
   - 选最优

3. 写正文（15 分钟）
   - 开头钩子
   - 核心内容
   - 结尾引导

4. 配图（5 分钟）
   - Canva 模板
   - 加文字

5. 发布（2 分钟）
   - 添加话题
   - 定时发布
```

### 知乎创作流程（60 分钟/篇）
```
1. 选题（10 分钟）
   - 找热门问题
   - 评估回答空间

2. 大纲（10 分钟）
   - 核心观点
   - 论据案例

3. 写作（30 分钟）
   - 开头引入
   - 正文论述
   - 结尾总结

4. 优化（10 分钟）
   - 加粗重点
   - 添加图片
   - 检查错别字
```

### 抖音创作流程（90 分钟/个）
```
1. 脚本（20 分钟）
   - 写台词
   - 设计画面

2. 拍摄（30 分钟）
   - 准备道具
   - 录制视频

3. 剪辑（30 分钟）
   - 剪映剪辑
   - 加字幕特效

4. 发布（10 分钟）
   - 写文案
   - 选 BGM
   - 添加话题
```
