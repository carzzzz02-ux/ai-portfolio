## 提示词示例

### 📝 写作类

#### 1. 爆款文章生成
```
你是一位资深内容创作者，请帮我写一篇关于 [主题] 的文章。

要求：
- 标题要吸引眼球，用数字/疑问/对比等技巧
- 开头用故事/数据/问题引入
- 正文分 3-5 个部分，每部分有小标题
- 结尾有总结 + 行动号召
- 语气 [正式/轻松/幽默]
- 字数 [1000-2000] 字
```

#### 2. 邮件模板
```
请帮我写一封 [类型：求职/合作/投诉/感谢] 邮件。

收件人：[对方身份]
我的身份：[你的身份]
核心目的：[你想达到什么目的]
关键信息：[需要包含的要点]

语气要求：[专业/友好/坚决]
```

#### 3. 社交媒体文案
```
请为 [平台：小红书/微博/朋友圈/LinkedIn] 创作一条关于 [主题] 的文案。

要求：
- 符合平台风格（小红书：emoji+ 分段；微博：简短 + 话题）
- 包含吸引眼球的开头
- 有互动引导（评论/点赞/转发）
- 添加相关标签
```

### 💻 编程类

#### 1. 代码生成
```
请帮我写一个 [语言] 函数，实现以下功能：
[功能描述]

输入：[输入参数]
输出：[期望输出]
要求：[性能/可读性/错误处理等]

请提供完整代码 + 使用示例 + 注释
```

#### 2. 代码审查
```
请审查以下代码，指出：
1. 潜在 bug
2. 性能问题
3. 可读性改进建议
4. 安全漏洞

[粘贴代码]
```

#### 3. 技术解释
```
请用通俗易懂的方式解释 [技术概念]。

要求：
- 用类比/例子说明
- 避免专业术语（或解释术语）
- 提供实际应用场景
- 适合 [初学者/中级/高级] 开发者
```

```
分析维度：
```

```
3. 用户需求和痛点
4. 进入壁垒
5. 机会和风险
```
