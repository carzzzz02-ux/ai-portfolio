## 一、写作类提示词（100 个）

### 1.1 小红书文案

```
你是一位资深小红书博主，擅长写爆款笔记。请帮我写一篇关于【主题】的小红书文案。

要求：
- 标题要吸引眼球，使用 emoji 和感叹号
- 正文语气活泼，像跟闺蜜聊天
- 包含 3-5 个核心卖点/知识点
- 适当使用 emoji（每段 2-3 个）
- 结尾引导互动（点赞/收藏/评论）
- 添加 5-8 个相关话题标签
- 字数 600-800 字
```

```
请帮我改写这篇文案，让它更符合小红书风格：
- 开头加一个吸引眼球的标题（带 emoji）
- 把长句拆成短句，每句不超过 20 字
- 添加适当的表情符号
- 结尾加一个互动问题
- 添加相关 hashtags
```

```
要求：
- 标题：提供 5 个备选（包含数字、疑问、对比等技巧）
- 开头：用故事/数据/问题引入，200 字以内
- 正文：分 3-5 个小标题，每个标题下有具体案例
- 结尾：总结要点 + 引导行动（关注/转发/评论）
- 字数：2000-3000 字

```

## 三、编程类提示词（100 个）

### 3.1 代码解释

```
请帮我解释这段代码。

代码：【粘贴代码】

要求：
- 逐行解释代码的功能
- 说明使用的核心概念/算法
- 指出可能的优化点
- 给出使用示例
- 用通俗易懂的语言（假设我是编程新手）
```

### 3.2 Bug 调试

```
请帮我调试这段代码。

代码：【粘贴代码】
错误信息：【粘贴错误提示】
期望行为：【描述应该发生什么】
实际行为：【描述实际发生了什么】

要求：
- 分析可能的原因
- 提供修复方案
- 解释为什么这样修复
- 给出预防类似问题的建议
```

### 3.3 代码重构

```
请帮我重构这段代码。

代码：【粘贴代码】

要求：
- 提高可读性（命名、注释）
- 优化性能（时间/空间复杂度）
- 增强可维护性（模块化、解耦）
- 遵循最佳实践
- 提供重构前后的对比说明
```

### 3.4 功能实现

```
请帮我实现一个功能。

需求：【详细描述功能】
编程语言：【Python/JavaScript/Java 等】

输出：【期望的输出格式】

要求：
- 提供完整可运行的代码
```

## 五、分析类提示词（70 个）

### 5.1 SWOT 分析

```
请帮我对【公司/产品/项目】进行 SWOT 分析。

背景信息：【粘贴相关信息】

要求：
- Strengths（优势）：3-5 点
- Weaknesses（劣势）：3-5 点
- Opportunities（机会）：3-5 点
- Threats（威胁）：3-5 点
- 每点要有具体依据
- 最后给出战略建议（3 条）
```

### 5.2 竞品分析

```
请帮我分析【产品名】的竞品。

核心竞品：【列出 2-3 个】
分析维度：
- 产品功能
- 定价策略
- 目标用户
- 营销方式
- 优劣势

要求：
- 用表格对比呈现
- 每个维度详细分析
- 找出差异化机会
- 给出建议（3-5 条）
```

### 5.3 用户画像

```
请帮我创建【产品/服务】的用户画像。

产品信息：【描述】

要求：
- 创建 3 个典型用户画像
- 每个画像包含：

  - 行为特征（使用习惯/偏好）
```

## 六、学习类提示词（50 个）

### 6.1 概念解释

```
请用费曼学习法解释【概念】。

要求：
- 用初中生能理解的语言
- 用生活中的例子类比
- 避免专业术语（如必须使用，请解释）
- 包含一个简单的小测试（3 道题）
- 控制在 500 字以内
```

### 6.2 学习路径

```
请帮我制定一个【技能/学科】的学习路径。

当前水平：【零基础/入门/进阶】
可用时间：【每天 X 小时，持续 X 周】
学习目标：【达到什么水平】

要求：
- 分阶段规划（入门 - 进阶 - 精通）
- 每个阶段列出：
  - 学习内容
  - 推荐资源（书籍/课程/网站）
  - 练习题/项目
  - 预计时间
- 给出检验学习成果的方法
```

### 6.3 知识总结

```
请帮我总结【主题/书籍/课程】的核心知识点。

内容：【粘贴内容或列出主题】

要求：
- 提取 5-10 个核心概念
- 每个概念用一句话定义
- 用思维导图结构呈现
- 标注知识点之间的关联
- 给出 3 个应用示例
```

### 6.4 自测题目

```
请根据我学的内容出一些自测题。

学习主题：【填写主题】
已学内容：【简要描述】

要求：
- 5 道选择题（附答案和解析）
- 3 道简答题（附参考答案）
- 2 道应用题（附解题思路）
- 难度梯度：基础 - 进阶 - 挑战
- 覆盖所有核心知识点
```

## 七、提示词使用技巧

### 7.1 万能公式

```
角色 + 任务 + 要求 + 格式 + 目标受众 = 高质量输出
```

### 7.2 优化技巧

1. **具体化**：越具体越好，避免模糊描述
2. **示例化**：给出例子，让 AI 理解你的期望
3. **迭代化**：不满意就继续追问，让 AI 优化
4. **约束化**：给出限制条件（字数/格式/风格）

### 7.3 常见错误

❌ "帮我写篇文章"（太模糊）
✅ "帮我写一篇 800 字的小红书文案，主题是 AI 工具推荐，语气活泼，带 emoji"

❌ "这个代码有问题"（信息不足）
✅ "这段 Python 代码报错 XXX，期望输出 XXX，实际输出 XXX，请帮我调试"

## 八、高级技巧

### 8.1 链式提问

```
第一轮：请列出【主题】的 10 个核心概念
第二轮：请详细解释第 3 个概念
第三轮：请给这个概念举 3 个例子
第四轮：请出 5 道题测试我是否理解
```

### 8.2 角色扮演

```
你现在是【角色】，请用【角色】的视角和语言风格回答问题。

背景：【情境描述】
任务：【具体任务】
```

### 8.3 反向提问

```
在我开始【任务】之前，请问我 5 个关键问题，
帮助你更好地了解我的需求，然后再生成内容。
```
