## ✅ 优点

### 1. 长文本处理能力无敌
- 可以一次性读完 200 页文档
- 精确找到你问的信息在哪一页
- 写摘要、提取要点非常准确

### 2. 写作能力细腻
- 文章有"人味"，不像机器写的
- 能模仿各种风格（正式、轻松、幽默）
- 修改润色能力超强

### 3. 安全性高
- Anthropic 主打"有益、诚实、无害"
- 不会输出有害内容
- 适合企业使用

### 4. 免费版本够用
- 免费版每天有一定使用次数
- 对于轻度用户完全够用

---

## ❌ 缺点

### 1. 没有联网功能
- 无法访问实时信息
- 知识截止训练数据日期

### 2. 代码能力稍弱
- 能写代码，但不如 GPT-4 专业
- 复杂编程任务还是推荐 ChatGPT

### 3. 没有语音功能
- 只能文字交互
- 没有语音对话模式

### 4. 国内访问不稳定
- 需要特殊网络环境

---

## 💡 使用场景推荐

### ✅ 适合用 Claude 的场景
- 阅读长文档/论文/报告
- 写作润色/改写
- 提取文档关键信息
- 创意写作（小说、剧本）
- 翻译（尤其是文学类）

### ⚠️ 更适合用 ChatGPT 的场景
- 编程相关
- 需要实时信息
- 数据分析
- 多模态任务（图片识别等）

## 📝 Claude 提示词技巧

### 1. 文档分析
```
请帮我分析这份文档：
[粘贴文档或上传文件]

我需要了解：
1. 核心观点是什么？
2. 有哪些关键数据？
3. 结论是否可靠？
4. 有什么潜在问题？
```

### 2. 文章润色
```
请帮我润色以下文章：
[粘贴文章]

要求：
- 保持原意不变
- 让语言更流畅自然
- 修正语法错误
- 优化段落结构
```

### 3. 创意写作
```
请帮我写一篇关于 [主题] 的 [类型：散文/小说/诗歌]。

风格要求：[如：温暖治愈/悬疑紧张/幽默轻松]
字数：[约 XXX 字]
目标读者：[如：年轻人/职场人/学生]
```
